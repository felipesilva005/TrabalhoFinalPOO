# Trabalho Final POO
A aplicação é referente ao trabalho final da cadeira de Programação Orientada a Objetos(POO).

# Tema: Sistema de Gerenciamento de Abrigos e Resgate de Animais
O tema escolhido foi o Sistema de Gerenciamento de Abrigos e Resgate de Animais, a aplicação foi totalmente desenvolvida seguindo o enunciado e regras do Trabalho.

# Organização
O Trabalho está organizado em pastas, para melhor vizualização e entendimento de cada funcionalidade presente no projeto.

# Tecnologias/Extras
O Trabalho foi inteiramente produzido em Java seguindo os pilares da programação orientada a objetos, com domunentação clara a partir do nome das classes e comentários adicionados, como extra ultilizei Git e GitHub.
